# روال ۲.۸.۸ — نشانگر «مشاور هوشمند»: گوشهٔ چپ، موچک‌تر

> «نشانگر مشاور هوشمند در سمت چپ باشد و ابعادش رو کمی موچک‌تر کن.»

## چه چیزی عوض شد

| | قبل | بعد |
|---|---|---|
| **جای نشانگر** | گوشهٔ راست-پایین (`inset-inline-start` در چیدمان راست‌به‌چپ) | **گوشهٔ چپ-پایین** (`left:16px`) |
| **ارتفاع** | ~۴۰ پیکسل | **~۲۷ پیکسل** |
| **عرض** | ~۱۵۰ پیکسل | **~۱۰۰ پیکسل** |
| **اندازهٔ متن** | ۱۳ | **۱۱٫۵** |
| **آیکن** | ۱۷×۱۷ | **۱۳×۱۳** |
| **سایه** | `0 12px 30px` | ملایم‌تر: `0 8px 20px` |

- سمتِ چپ منطقی است: **پنل گفت‌وگو هم از چپ باز می‌شود**؛ قبلاً دکمه یک طرف بود و پنل طرف دیگر.
- لبه‌ها عمداً **فیزیکی** نوشته شدند (`left` نه `inset-inline-start`)، چون قاعدهٔ `main, aside{direction:ltr}` قبلاً همین‌جا دکمه را به سمت اشتباه انداخته بود؛ الان به جهتِ سند وابسته نیست.
- روی موبایل (≤۷۶۰px): فاصله ۱۲px و فونت ۱۱px.
- رفتار قبلی دست‌نخورده: با کلیک، پنل باز می‌شود و خودِ نشانگر به «بستن» تبدیل می‌شود؛ کلید میان‌بر Ctrl+I هم سرِ جایش است.
