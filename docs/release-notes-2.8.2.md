# روال ۲.۸.۲ — «فصل ۱» + عنوان واقعی فصل

> «فقط نوشتی فصل ۱ یا فصل ۲، در حالی که علاوه بر شمارهٔ فصل، باید عنوان فصل هم ذکر شود تا کاربر بفهمد فصل ۱ دربارهٔ چه مبحثی بوده.»

## چه چیزی عوض شد

در بخش **دروس و تسلط → ارزیابی فصل‌به‌فصل**، هر سطر حالا **دو چیز را با هم** نشان می‌دهد:

```
[فصل ۱]   دهم · الگو و دنباله
[فصل ۲]   دهم · مثلثات
[فصل ۳]   دهم · توان‌ها و عبارت‌های جبری
```

| | |
|---|---|
| **نشان شمارهٔ فصل** | «فصل ۱» به‌صورت یک نشان آبی، جدا از عنوان — شماره همیشه دیده می‌شود. |
| **عنوان واقعی کتاب** | از فهرست رسمی سرفصل‌های کتاب‌های درسی (همان چیزی که در خودِ کتاب می‌بینی). |
| **درس‌های عمومی** | نشان به‌جای «فصل» می‌گوید **«درس ۱»** (فارسی، عربی، دینی، زبان، سلامت، هویت). |
| **پایه** | اگر پایه در عنوان نباشد، برچسب «دهم/یازدهم/دوازدهم» کنارش می‌آید. |
| **هیچ سطر خالی** | اگر برای درسی عنوانی در داده نبود، خودِ «فصل N» در کادر می‌نشیند تا سطر بی‌معنی نماند. |
| **ترمیم خودکار** | سطرهایی که در نسخه‌های قبل بدون عنوان ذخیره شده‌اند، هنگام باز شدن همین بخش با عنوان واقعی کتاب پر می‌شوند — چیزی از دست نمی‌رود. |
| **قابل ویرایش** | عنوان هر فصل را می‌توانی دستی هم عوض کنی (مثلاً اگر کتابت چاپ دیگری است). |

سرصفحهٔ ستون از «فصل / مبحث» به **«فصل و عنوان»** تغییر کرد و کادر عنوان یک جای‌نگهدار راهنما دارد:
`فصل ۱ — عنوان از کتاب درسی (مثلاً «مثلثات»)`

## آزمون
